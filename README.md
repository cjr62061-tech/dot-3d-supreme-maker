# DOT 3D Supreme

Convert any image to 3D model.

## What it does
This app converts your photo (jpg/png) into a 3D model file (OBJ and GLB).

## How to use
1. Put your image in the folder and name it photo.jpg
2. Run the script: python image_to_3d.py
3. You will get model.obj

## Features
- Fast
- Works offline
- No watermark
